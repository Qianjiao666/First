Date: 2026-08-13

## Delivered scope

- Cross-page Supabase session initialization and global auth-state synchronization.
- Login prompt for protected forum and task actions; expired sessions request re-login.
- Frontend and backend XSS guards for public text inputs.
- Code-only DFA sensitive-word filtering across forum, tasks, categories, announcements, shop and related public text surfaces.
- Three themes with local persistence: tech light, tech dark and fresh blue.
- Shared modal, table, responsive navigation and mobile presentation rules.
- Existing avatar rendering with approved public URLs and text fallback.
- Avatar database, Storage and fail-closed moderation code retained for a future enabled release.

## Deferred scope

Avatar upload is not part of this delivery. The settings dialog does not expose a file input or upload command.

The real Tencent IMS request reached the service but returned:

```text
UnauthorizedOperation.Unauthorized
```

Tencent documents this as missing service permission, no valid package or account arrears. The upload backend remains fail closed and rejected requests did not create a Storage object. Re-enable the browser upload only after the Tencent service is active, the credential owner has `QcloudIMSFullAccess`, and real Pass/Review/Block smoke tests succeed.
