# 航线 v1.0 全站视觉重构设计规格

## 目标

在不改变任何既有业务功能、页面路由、表单字段、数据契约、事件选择器、Supabase 行为和权限逻辑的前提下，对航线全站进行一次显著的视觉升级。升级范围覆盖首页、社区入口、论坛、任务广场、商城、公告、通知组件和管理后台。

## 设计方向

视觉世界定义为“职业校准台”：像一套安静、精密、可信的导航与测量系统，而不是营销模板或游戏化面板。

- 基础色使用墨黑、纸白和冷灰，保证长时间阅读与高密度操作的清晰度。
- 航线蓝用于主要动作、定位和关键数据；信号绿用于完成、声望和在线状态；警示橙只用于奖励与需要注意的状态。
- 中文正文使用本机高质量系统字体栈；DM Mono 仅用于数据、时间、版本和测量标签。
- 首页具有更强的品牌张力和空间节奏；论坛、任务与后台保持紧凑、可扫描、可重复操作。
- 视觉记忆点是“校准轨迹”：细线、刻度、状态点和精确的色块共同表达从目标到行动的路径，但不把界面装饰成地图或仪器仿制品。

## 视觉系统

### 色彩

- `--hx-ink: #111820`：标题、主要文本、深色表面。
- `--hx-paper: #f4f7f8`：全站背景。
- `--hx-surface: #ffffff`：表单、卡片和操作表面。
- `--hx-blue: #165dff`：主要动作与定位。
- `--hx-green: #087f5b`：成功、声望和正向状态。
- `--hx-orange: #d66b18`：奖励与注意状态。
- `--hx-line: #d8e0e5`：分隔与边界。

色彩不能单独承担状态含义，必须保留文字、图标或结构提示。正文与背景对比度达到 WCAG AA。

### 排版

- 标题使用明确的粗细和紧凑行高建立层级，不随视口连续缩放。
- 正文默认不少于 15px，长文本行宽控制在 65 至 75 个字符。
- 紧凑面板、卡片和侧栏标题不使用英雄级字号。
- 禁止负字距超过 `-0.04em`；中文界面默认字距为 `0`。

### 形状与深度

- 卡片圆角统一为 6 至 8px，工具按钮和输入框为 5 至 7px。
- 卡片使用边界或阴影中的一种主要深度手段，避免边框叠加浓重阴影。
- 小状态标签可以使用胶囊形；普通文字按钮不使用无意义的大胶囊。

### 动效

- 保留现有滚动显现、报告进入和状态切换，但调整为快速、克制的指数缓出。
- 主要操作提供按压位移；卡片悬停只做轻微抬升或边界变化。
- 完整支持 `prefers-reduced-motion: reduce`，内容默认可见，动效不得阻挡交互。

## 页面策略

### 首页

- 保留当前首屏内容、评估入口和全部内容模块。
- 提高首屏信息密度和品牌对比，缩短空洞纵向区域。
- 将评估卡塑造成核心产品界面，而不是装饰性浮卡。
- 统一流程、报告、案例、团队、文章、FAQ、账户和留言板的视觉语法。

### 社区、论坛和任务

- 社区入口作为首页与操作模块间的过渡页，保留论坛与任务两项选择。
- 论坛采用信号板布局：分类、信息流、筛选和排序在桌面端有清晰分工，移动端成为连续单列。
- 任务广场突出搜索、筛选、奖励和任务状态；任务卡保持可扫描，不添加无关装饰。

### 商城、公告和后台

- 商城使用奖励橙作为局部强调，不改变兑换逻辑。
- 公告强调阅读层级、日期、置顶和编辑状态。
- 后台保持高密度表格与表单，改善侧栏定位、表头、行悬停、按钮状态和移动端横向处理。

## 实现边界

- 新增 `assets/css/visual-v1.css`，并作为所有生产 HTML 页面最后加载的视觉覆盖层。
- 不改变现有 `id`、`data-*`、表单 `name`、链接目标和脚本加载顺序。
- 只在视觉覆盖确实无法表达设计时才调整非功能性 HTML；默认不改 DOM 结构。
- 不引入外部字体、图标、图片 CDN 或构建依赖。
- 所有生产页面使用同一个带版本查询参数的视觉层 URL。

## 公开版本规则

- 用户可见更新日志只使用 `v0.x` 或 `v1.x`。
- 旧 `r8` 映射为 `v0.7`，旧 `r8.1` 映射为 `v0.8`。
- 本次全站视觉重构为 `v1.0`。
- `r` 前缀仅可作为内部构建包 revision，不得出现在公开更新日志入口、标题、日期或正文版本标识中。

## 验收标准

- 所有现有 Node 测试继续通过。
- 所有生产 HTML 加载 `assets/css/visual-v1.css?v=20260812-v1.0`。
- 公开更新日志按 `v1.0`、`v0.8`、`v0.7`、`v0.6` 排序，且不包含 `r` 版本标签。
- 375、768、1280、1920 四种宽度无横向溢出、文字裁切、交互重叠或运行时异常。
- 首页、社区、论坛、任务、商城、公告和后台均呈现同一品牌系统，同时保持各自操作密度。
- 键盘焦点、按钮悬停/按压、禁用、加载、错误、成功和空状态可辨认。
- 静态发布包不包含 schema、测试或后端源码，清单与 SHA-256 校验通过。
